# 🎯 Ruleta de Nombres

Una aplicación web interactiva que permite seleccionar participantes de forma aleatoria mediante una ruleta animada. Ideal para dinámicas escolares, actividades grupales, sorteos y selección de ganadores.

🌐 **Prueba la aplicación:** https://ruleta.dalu.bid/

## ✨ Características

- 🎡 **Ruleta interactiva:** gira la ruleta y selecciona un participante aleatoriamente.
- 📝 **Carga de participantes:** agrega nombres mediante un campo de texto, colocando uno por cada línea.
- 🏆 **Selección de ganadores:** muestra el nombre de la persona seleccionada.
- 📋 **Historial de ganadores:** consulta los resultados anteriores.
- 💾 **Nombres utilizados:** guarda los nombres utilizados anteriormente en el dispositivo.
- 📱 **Diseño adaptable:** funciona en computadoras, tabletas y teléfonos.
- 📲 **Instalable:** puede utilizarse como aplicación web instalable (PWA).

## 🚀 ¿Cómo funciona?

1. Ingresa a https://ruleta.dalu.bid/
2. Escribe los nombres de los participantes.
3. Coloca cada nombre en una línea diferente.
4. Presiona **GIRAR RULETA**.
5. Espera a que la ruleta seleccione al ganador.
6. Consulta el historial cuando lo necesites.

## 🖥️ Tecnologías

Proyecto desarrollado utilizando tecnologías web y desplegado mediante Cloudflare.

- HTML5
- CSS3
- JavaScript
- Cloudflare Pages

## 🗂️ Estructura del proyecto

- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos y diseño adaptable.
- `app.js`: lógica de la ruleta, participantes y sus historiales.
- `manifest.webmanifest`: metadatos de la aplicación instalable.
- `sw.js`: caché y funcionamiento sin conexión.

## 💾 Almacenamiento

Los nombres utilizados anteriormente se guardan localmente en el dispositivo del usuario, permitiendo reutilizarlos en futuras sesiones.
